# Tails Announcer Arknights (TAA)

明日方舟「卫戍协议」屏幕状态语音播报。程序只截取游戏窗口画面，识别战斗、商店、结算等状态并播放对应语音。

**不点击、不注入、不读游戏内存、不联网。**

> 非官方工具，与鹰角网络无关。使用前请阅读文末的合规与风险说明。

## 功能

- 实时监控：以约 4 fps 抓帧 → 识别 → 播报，全部在本机完成
- 流程：进入模式、匹配成功、策略选择、决策页、隐秘核心、结算页、返回主页、快速离开
- 战斗：进入战斗、完美/轻微/重创、濒死/战败、最终攻势、首领血量里程碑、倒计时里程碑、击败首领
- 联防：进入联防，以及 `help/helped/peer × full/basic/fail` 九种结果
- 休整与商店：休整开始（普通/Boss 前）、购买低阶/高阶、购买道具、售出、连续刷新、升级/可升级、冻结/解冻、三连奖励、同名干员
- 闲置提醒：休整期闲置、主页闲聊
- 语音包：zip 包，多包切换、监控中热切换、音量滑杆、按分类开关
- 截图测试：抓一帧跑完整检测，黑帧/超时不通过，避免「灯亮着但读不到画面」

完整 key 列表见 [docs/KEYS.md](docs/KEYS.md)。

## 运行要求

- Windows 10 / 11（依赖 `PrintWindow`、`winsound`、Tk）
- 游戏以管理员权限运行时，本程序也必须以管理员运行，否则只能抓到黑帧（与 OBS 管理员采集同理）
- 源码运行：Python 3.12+（开发机为 3.14）

## 快速开始（源码）

```bat
pip install -r requirements.txt
start.bat
```

也可以在命令行运行 `python app\gui.py`。

使用流程：

1. 启动游戏并进入卫戍协议
2. 在窗口下拉框选择游戏窗口
3. 点「截图测试」，确认分辨率、抓帧耗时和识别读数正常
4. 点「开始监控」

窗口尺寸建议 16:9。识别区域以 1920×1080 为规范坐标，其他 16:9 分辨率按比例缩放；150% DPI 已适配。

## 语音包

仓库**不附带语音**（配音版权原因）。`packs/` 为空时程序照常启动，只是没有声音。

自己制作语音包：

1. 准备若干 wav（44.1k / 16-bit / 单声道即可），文件名就是 key：`battle_enter.wav`
2. 同一 key 的随机变体加后缀：`battle_enter_2.wav`、`battle_enter_3.wav`
3. 打包：

```bat
python tools\voice_pack_tool.py --src <wav目录> --out packs\mypack.zip --name 我的语音包
```

也可以双击 `tools\voice_pack_tool.bat` 用图形界面打包。工具会提示程序不会用到的文件名（通常是拼写错误）。

包内缺少的 key 只会在日志里跳过，不会报错；程序自带兜底，不会因为少一条语音中断。

## 构建 exe

```bat
build.bat
```

产物在 `dist\TAA_TailsAnnouncerArknights\`（PyInstaller one-dir）。`packs\*.zip` 会复制到 exe 同级目录，`start.bat` 负责请求管理员权限。

## 隐私

- 不发起任何网络请求，不上传截图或日志
- 抓帧、日志、截图测试存档只写在本地 `_logs\`、`_shots\`，已被 `.gitignore` 忽略
- 语音包解包缓存写在 `_volume_cache\`
